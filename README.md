# Neon Spiral Animation in Python 🐍✨

A mesmerizing and colorful geometric spiral animation built using Python's built-in `turtle` graphics library. 

## 🚀 Features
- **Dynamic Color Shifting:** Alternates between vibrant red and yellow hues.
- **Geometric Patterns:** Combines forward motion, dynamic radius circles, and precise rotational angles to form a complex spiral design.
- **Dark Mode Theme:** Features a sleek black background to make the glowing pattern stand out.

## 🛠️ Prerequisites
You don't need any external or third-party libraries! Python comes with `turtle` pre-installed. Just make sure you have **Python 3.x** installed on your system.
